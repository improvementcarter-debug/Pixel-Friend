🔐 PERMANENT ADMIN SETUP

If your database does not yet have profiles.role, run the SQL below once in Supabase SQL Editor. The browser never uses a service-role key.

ALTER TABLE public.profiles
ADD COLUMN IF NOT EXISTS role text NOT NULL DEFAULT 'user';

UPDATE public.profiles
SET role = 'admin'
WHERE id = auth.uid();

For production, use RLS policies so only trusted admins can change roles.
