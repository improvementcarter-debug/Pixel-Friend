Your UI admin is based on the CARTER username. For permanent database admin, set the role in Supabase SQL.

🔐 Permanent Admin Setup

Run this in Supabase SQL Editor after replacing the email:

UPDATE public.profiles p SET role = 'admin' FROM auth.users u WHERE p.id = u.id AND lower(u.email) = lower('YOUR_EMAIL_HERE');

If RLS blocks role changes, do this from the SQL Editor rather than the browser.
